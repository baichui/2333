# wuwa_luck (AstrBot)

鸣潮主题「今日运势」白底卡片，AstrBot Star 插件版。

## 指令

- `/luck`
- `/今日运势`

## 安装

放到 AstrBot 插件目录：

```
<AstrBot>/data/plugins/wuwa_luck/
  main.py
  metadata.yaml
  data.py
  image.py
  assets/bg.png
```

重启 AstrBot 后在 WebUI 启用。

## 说明

- 基于洛谷运势修改：[plugin-luoguluck](https://github.com/LiteSuggarDEV/plugin-luoguluck)
- 同 UID + 昵称 + 日期当天结果固定。
- 共鸣指引：小爱（爱弥斯）约 80%。
- 谐振指数：限定池 / 武器池 / 声骸调谐。
